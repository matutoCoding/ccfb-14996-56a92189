# Mosaic Light Studio

浏览器端马赛克壁画排块、WebGL2 光照预览与施工图系统。全部项目、原稿、排块、材料库存和版本历史都保存在浏览器 IndexedDB，不上传服务器。

## 启动

需要 Node.js 20+ 和 pnpm。依赖尚未安装时，请由主人执行：

```powershell
pnpm install
pnpm dev
```

构建与类型检查：

```powershell
pnpm build
pnpm preview
```

仅做类型检查：

```powershell
pnpm exec tsc --noEmit
```

## 已实现工作流

1. **项目列表**：项目按墙面管理；支持平面墙、弧形墙和教堂半穹顶，可设置宽高、曲率半径和朝向方位角。
2. **原稿处理**：导入本地 PS/照片稿，或使用内置生成的人像、几何图案、半穹顶星芒稿。Sobel 轮廓切线、双向角平滑和肤色椭圆先验生成人脸/衣褶引导线。
3. **排块编辑**：确定性种子生成；可调块径、缝宽、切割随机度、角度抖动、倾角和引导跟随。支持点选、拖动单块、替换材料、调平面角和三维倾角。
4. **材料库**：玻璃、金箔、石材三类；维护颜色、透明度、粗糙度、反光、表面起伏、金属度和库存/安全库存。
5. **Lab 配色**：sRGB → XYZ D65 → Lab，距离使用 CIEDE2000，不是 RGB 欧氏距离。输出用色数量、缺色和库存缺口警告。
6. **光照预览**：WebGL2 Instanced Rendering，每块独立位置、尺寸、平面角和双轴倾角；支持白天自然光、射灯、蜡烛。金箔使用金属 BRDF、微切面和视角相关锐高光，视角移动时闪光随之变化。
7. **死白标记**：预览页可开启过曝/低饱和区域覆盖标记，用于发现灯下连成一片的死白反光带。
8. **施工图**：按 1m 分格选择图幅，真实米制 Canvas 出图；每块绘制材料颜色编号，倾角过大的块带铺贴标记。支持单张打印、全部分格打印和 BOM CSV。
9. **版本历史**：生成、重新匹配、拖动和手动检查点都会写入 IndexedDB；任意历史版本可恢复，并会追加一条恢复检查点。
10. **测试数据**：首次启动自动生成材料库，以及人像墙、几何/20㎡压测墙、半穹顶示例。

## 20 万块性能设计

- 每块只有一个实例，通过一次 WebGL2 `drawArraysInstanced(TRIANGLE_STRIP, 0, 4, count)` 提交全部块。
- 位置、尺寸、角度、倾角使用 `Float32Array`；材料编号使用 `Uint32Array`。
- 颜色和材质参数按材料编号展开到实例属性，避免每块一次 draw call。
- DPR 上限为 1.55，默认开启深度测试和高优先级 GPU context。
- 点选使用独立 R32/RGBA 实例 ID 拾取缓冲，不在 CPU 遍历二十万块。
- 20㎡、约 20 万块参考参数：`5m × 4m` 墙面，块径 `9mm`、缝宽 `1mm`。在排块页选择「20万块压测参数」即可。

## 确定性

相同墙面尺寸、种子、块径、缝宽、切割随机度会得到相同结果。随机数来自字符串种子派生的 `mulberry32`，不使用 `Math.random()` 参与排块。

## 目录

```text
src/core       类型、Lab/CIEDE2000、几何、引导线、排块、BOM、样稿
src/db         IndexedDB 封装和首次种子数据
src/render     WebGL2 着色器、实例化渲染器、相机和灯光
src/pages      六个主页面
src/state      数据访问和版本动作
src/ui         DOM、表单、弹窗等无框架 UI 工具
```

## 关键操作

- 排块页：左键选块/拖动；右键拖动旋转；Shift + 左键拖动平移；滚轮缩放。
- 预览页：左键旋转，滚轮缩放；「模拟人走过」会缓慢改变观察角度以检查金箔闪光。
- 施工图：浏览器打印对话框中选择背景图形开启，可另存为 PDF。
